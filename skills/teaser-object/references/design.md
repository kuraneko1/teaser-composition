# 象徴的な立体と静かな舞台 — 構成の読み

これらは画像の見え方からの解釈。作者の発言や公式の制作意図ではない。

## 統合した理由

耳、巨大なガラス数字、結晶、マスコットと周辺注釈を「単一の象徴立体＋低密度の舞台」として統合。物体の単独提示と注釈付きの製品カードは別モードで保持。

## 構成

機能を説明する代わりに、一つの立体へ触覚と期待を凝縮する。耳は聴くこと、透明な数字は明晰さ、キャラクターは親しみを担い、背景はその象徴を持ち上げる舞台。

物体の高さは画面の50–78%。単独なら中心より少し右、注釈付きなら主役を x=55–70%へ。影は床を説明するために控えめに。周辺注釈は主役の外側に弧状に配置する。

## 応用

結晶からレンズ・彫刻・オリジナルキャラへ。象徴が何を伝えるかを先に決める。
