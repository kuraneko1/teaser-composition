# Teaser Composition

ティザー画像やキービジュアルを、主役の大きさ・余白・視線・文字組みから設計し、コードで制作するための Codex スキル集です。構図の骨格を参考にしながら、題材に合う新しいビジュアルへ展開します。

## 特徴

- 余白、幾何学、製図、ピクセル、光、流れ、コラージュ、標本、立体、天体、風景、作例の12種類の構図から選択
- タイトルの実際の文字で複数の書体を比較し、字間や改行、縮小時の見え方まで調整
- 画像生成や提供画像は必要な素材に限定し、文字と配置はコードで制御
- 各構図のスターターコードと設定例を同梱

## インストール

このリポジトリをクローンし、`skills/` 内の全ディレクトリを Codex のスキルディレクトリへコピーします。構図別の12スキルはメインスキルから参照されるため、まとめてインストールしてください。

```bash
git clone https://github.com/kuraneko1/teaser-composition.git
mkdir -p ~/.codex/skills
cp -R teaser-composition/skills/teaser-* ~/.codex/skills/
```

既に同名スキルがある場合、コピーすると既存ファイルが上書きされることがあります。必要に応じてバックアップしてください。スキルが認識されない場合は Codex を再起動してください。

## 使い方

Codex のチャットでスキル名と作りたい内容を伝えます。

```text
$teaser-composition 新しいAIモデルのティザーを、画像生成も使って3案作って。文字と配置はコードで仕上げて。
```

参考画像、用途、サイズ、表示したい文章、使いたい書体やブランド指定があれば一緒に伝えてください。制作には実行環境に応じた Python、Pillow、CairoSVG などが必要です。画像生成には利用可能な画像生成ツールが必要です。

## 構成

- [`skills/teaser-composition`](skills/teaser-composition/SKILL.md)：構図の選択、素材の扱い、タイポグラフィの指針
- `skills/teaser-*`：12種類の構図別スキルと描画スターター

参考画像についての構図分析を含みますが、第三者の参考画像自体は同梱していません。参照元のロゴやビジュアルを複製するのではなく、構図の考え方を別の題材に応用します。フォントや生成素材の利用・再配布条件は、それぞれの提供元で確認してください。
